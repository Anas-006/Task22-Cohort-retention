Task 22 – Cohort Retention Basics

Objective

Build a cohort retention analysis based on customer signup/first purchase month and understand customer retention over time.

Dataset

Online Retail II dataset.

Tools Used

- Python
- SQL

Analysis Performed

1. Removed records with missing Customer IDs.
2. Removed cancelled invoices.
3. Kept transactions with Quantity greater than 0.
4. Converted InvoiceDate into a date format.
5. Created Invoice Month.
6. Identified each customer's first purchase month as the Cohort Month.
7. Calculated Retention Month.
8. Created a cohort customer retention table.
9. Converted customer counts into retention percentages.
10. Created a cohort retention heatmap.

Key Insights

- Retention is highest during the first month.
- Retention generally decreases as the number of months increases.
- Retention varies across different customer cohorts.
- The heatmap makes retention patterns easier to compare across cohorts.
- Cohort analysis can help businesses understand repeat-purchase behavior and improve customer engagement.

Deliverables

- Cohort Retention Table
- Cohort Retention Heatmap
- Insights
